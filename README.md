# Prince Kyle Quintos — Portfolio

A personal portfolio for my Computer Engineering coursework, projects, and internship experience. Built with Vue 3, TypeScript, Vite, and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Tech used

- Vue 3 with `<script setup>`
- TypeScript
- Tailwind CSS
- Vite
